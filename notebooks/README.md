# NEXUS Notebooks

Exploratory analysis, ablation reports, and experiment notebooks.

## Usage

Notebooks are for exploration only — production code lives in `nexus/`.

## Suggested notebooks

1. **01_data_exploration.ipynb** — Inspect demo dataset, entity/event distributions
2. **02_feature_analysis.ipynb** — Feature correlations, importance rankings
3. **03_ablation_report.ipynb** — Visualize ablation ladder (behavioral → +graph → +temporal → ensemble)
4. **04_risk_calibration.ipynb** — Plot calibration curves, Brier scores
5. **05_graph_analysis.ipynb** — Community structure, PageRank distributions
